7How long a closed Ask conversation lives

Astra F02 · AskResultEntry.swift:54 · AskScreen.swift:44, :155

Every time Ask opens it builds a new journey; the exchanges and the half-typed draft are view state. Closing with X cancels the request in flight, and opening Ask again from the same result starts with an empty conversation. Someone who closes Ask to look at a number on the result, then comes back to keep going, finds their explanation gone. There is no authorised chat-history feature and nobody is proposing one; the question is only the lifetime of the thread while the same result is still open. This is separate from TF21-ASK-3 (backgrounding must not kill an in-flight Ask, in flight on PR 192) and from any global Ask tab. Fable did not raise it.
